포항세화고등학교 성적조회 데모 (정적 사이트)
================================================

[ 이 폴더는 무엇입니까 ]
index.html 하나로 동작하는 데모입니다. 빌드가 필요 없고 서버도 없습니다.
Netlify에 이 폴더를 통째로 끌어다 놓으면 즉시 열립니다.

[ 올리는 방법 ]
1. https://app.netlify.com/drop 접속
2. 이 폴더(netlify-demo)를 브라우저 창에 드래그
3. 몇 초 뒤 https://<임의이름>.netlify.app 주소가 발급됩니다

[ 파일 구성 ]
  index.html    화면과 로직 전부 (26KB)
  data.js       가상 학생 100명 데이터 (179KB)
  netlify.toml  보안 헤더 + 검색엔진 차단
  robots.txt    검색 노출 방지
  _headers      netlify.toml 미적용 시 대비

[ 반드시 알아두실 점 ]
- 등장하는 학생·보호자·교직원은 전원 컴퓨터가 만든 가상 인물입니다.
- 인증번호가 화면에 그대로 표시됩니다. 보안 기능이 아니라 화면 시연용입니다.
- data.js는 누구나 열어볼 수 있습니다. 실제 학생 정보를 넣지 마십시오.
- 실제 운영은 서버·DB·RLS가 있는 본 패키지(Next.js)로 하셔야 합니다.
